# Multi-source Disease Severity Grading

This project summarizes my current work on disease severity assessment using multi-source plant observations.

## Overview

The study integrates multiple sensing modalities for robust disease grading under heterogeneous field conditions. The focus is on plant-centered data alignment, multimodal representation learning, and interpretable severity assessment.

## Data sources

- Hyperspectral reflectance
- SPAD measurements
- UAV canopy sensing
- R-G-NIR canopy imagery
- 3D structural traits

## Core tasks

- Multi-source feature construction
- Cross-scale data alignment
- Multimodal fusion for disease grading
- Model interpretation and visual analysis

## Notes

This repository page serves as a lightweight project record. Full experiment scripts, training logs, and result tables are intentionally not exposed here in detail.
