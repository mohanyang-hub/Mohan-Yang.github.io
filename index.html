About

Profile

My research interests lie at the intersection of agricultural remote sensing, crop phenotyping, 3D scene reconstruction, and process-based simulation. I am particularly interested in how canopy structure, spectral response, microclimate, and disease development can be integrated to support precise crop monitoring and early warning.

Current work includes multi-source disease severity assessment, canopy radiative transfer simulation, and 3D environmental modeling for agricultural sensing and interpretation.

Research

Research Directions

Multi-source disease data acquisition

Building plant-centered datasets by combining spectral imagery, physiological observations, canopy structure, and disease annotations across multiple sensing scales.

Cross-scale multimodal disease monitoring

Fusing hyperspectral, SPAD, UAV canopy imagery, texture features, and 3D traits for robust disease severity assessment and interpretation.

Simulation-supported crop analysis

Combining 3D canopy modeling, radiative transfer, and environmental simulation to improve agricultural monitoring, inversion, and process analysis.

Selected Work

Helios / C++ / Greenhouse simulation

3D environmental simulation and analysis in CLion

This project builds greenhouse-scale 3D environmental simulation workflows in C++ for canopy analysis, with emphasis on scene construction, radiation processes, and disease-relevant environmental interpretation.

  • Input geometry: canopy, greenhouse wall, and roof scene files.
  • Core tasks: scene construction, environmental process simulation, and per-primitive analysis.
  • Outputs: scene-level variables for crop and disease-related analysis.
  • Implementation: CLion-based C++ project with modular simulation workflow.

LESS / Python / Hyperspectral simulation

LESS-based canopy radiative transfer simulation

This project uses LESS and pyLessSDK to construct canopy scenes and run hyperspectral radiative transfer simulation, supporting crop trait inversion, physiological interpretation, and remote sensing analysis.

  • Input data: canopy geometry and optical-property files.
  • Scene design: structured canopy placement with object-level variation.
  • Sensor setup: orthographic hyperspectral image simulation across visible and near-infrared bands.
  • Batch workflow: automated updates of optical inputs and repeated LESS simulation runs.

AMAF-Net / Python / Multi-source disease monitoring

Multi-source crop disease severity grading

This project integrates spectral, physiological, canopy image, and structural observations for disease severity assessment under heterogeneous field conditions. The work emphasizes plant-centered alignment, multimodal fusion, and interpretable severity grading.

  • Data sources: hyperspectral/SPAD, UAV canopy sensing, R-G-NIR imagery, and 3D structure.
  • Core tasks: multi-source feature construction, fusion modeling, and severity grading.
  • Model design: bottleneck-guided multimodal interaction with stage-aware attention weights.
  • Outputs: classification metrics, confusion matrices, and attention-weight visualizations.
